A one-page newspaper front page — **THE WORLD TODAY** — that sums up
Friday, 20 November 2026 in 41 stories: a giant masthead with the date,
a region strip, the day in numbers (Nikkei −4.6%, Kospi −4.7%, Asia −7%
on the week, 6,310 held in Korea's gambling sweep, $35bn of Citi risk),
three big hero stories, a ten-card world grid, a dotted world map with a
numbered brief list, and a DATE CHECK box.

Entry for the make.fun bounty: https://make.fun/c/news-image-20261120

## How it works

`entry.png` (900 × 1024) is drawn by `generate.py` with Pillow: every
illustration is an original flat drawing coded in the generator — no
photographs, no copied images. At grade time `main.py` (Python 3.13
standard library only) simply copies the finished image to
`$MAKEFUN_OUTPUT_DIR/entry.png`, so the run is deterministic and needs
no network.

## Files

- `entry.png` — the front page
- `main.py` — the entrypoint: copies `entry.png` to the output directory
- `generate.py` — the drawing program that built `entry.png`
